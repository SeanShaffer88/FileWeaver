# Governance

FileWeaver is a single-maintainer project.

- **Decisions.** The maintainer (see [MAINTAINERS.md](MAINTAINERS.md)) decides scope, architecture, and releases. Design rationale is recorded in [fileweaver-market-and-architecture.md](fileweaver-market-and-architecture.md) and [innovation-proposals.md](innovation-proposals.md).
- **Contributions** are welcome under the rules in [CONTRIBUTING.md](CONTRIBUTING.md); acceptance is at the maintainer's discretion, with the project's safety invariants (pure planning, no overwriting, journal-before-files) treated as non-negotiable.
- **Releases** are cut from tags by the maintainer after the CI gate passes; release contents are recorded in [CHANGELOG.md](CHANGELOG.md).
- **License.** MIT for all project code (see [../LICENSE](../LICENSE)); third-party components remain under their own licenses (see [CREDITS.md](CREDITS.md)).
