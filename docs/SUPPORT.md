# Support

Support is provided through the project's GitHub issue tracker:
<https://github.com/SeanShaffer88/FileWeaver/issues>

When reporting a problem, include:

- The FileWeaver version (`fileweaver --version`, or the version in the window title's About information).
- Your Windows version and edition.
- What you did, what you expected, and what happened instead.
- If the problem involves a job: the job's status in the Recovery ledger and the exact message shown.

Do not attach your operation ledger (`operations.sqlite`) to a public issue: it contains the full paths of files you have renamed. If a maintainer needs diagnostic detail, describe the relevant rows instead.

There is no support SLA and no paid support tier; FileWeaver is a free, MIT-licensed project maintained on a best-effort basis.
